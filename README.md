# Граница-99

Изометрическая игра на выживание. Юг Казахстана, 1999 год, граница с Узбекистаном.
После аварии на закрытом советском объекте «Мелиорация-7» над степью прошёл
«Пыльный фронт»: часть людей погибла, часть заболела, часть превратилась в «Серых».

Игра сделана по концепт-документу «Граница-99». Эта версия — **MVP** (раздел 16 концепта):
посёлок Сарыкудук, степь, колхоз «Заря», бункер «Подземка», Акты I «Пыль» и II «Колодец».

## Как играть

**Готовая сборка:** скачать архив `Granica99-win64.zip` из раздела Releases, распаковать
и запустить `Granica99.exe`. Python ставить не нужно.

**Из исходников:**

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python main.py
```

**Собрать .exe самому:** запустить `build.bat`, и папка с игрой появится в `dist\Granica99\`.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | ходить (Shift — бег, Z — красться) |
| ЛКМ | удар или выстрел в сторону курсора |
| E / ПКМ | взаимодействовать: обыскать, открыть, говорить, набрать воды |
| R | перезарядить |
| F | фонарик |
| B | заколотить окно |
| I / Tab | инвентарь (ПКМ по предмету — быстрое действие) |
| C | крафт |
| H | здоровье и раны |
| J | журнал: задания, навыки, персонаж |
| G | словарик казахских и узбекских слов |
| M | звук |
| F5 / F9 | сохранить / загрузить (обычный режим) |
| F11 | полный экран |
| Esc | пауза |

## Что есть в игре

- **Выживание:** голод, жажда, усталость, температура тела (днём жара до +35, ночью до +5), настроение.
- **Вода — главный ресурс:** колодцы-кудуки и арык дают грязную воду. Её нужно кипятить на костре или фильтровать, иначе отравишься.
- **Раны по частям тела:** порезы, укусы, ушибы, переломы. Помогают бинты, зелёнка, шины. Грязная повязка может воспалиться.
- **Пыльная болезнь:** кашель → лихорадка → бред → смерть. Защищают респиратор, противогаз и укрытие. Лечат антидот и отвар колючки.
- **Инвентарь с весом**, экипировка (одежда, рюкзак, респиратор, фонарик), обыск контейнеров.
- **Крафт:** 16 рецептов, станции «огонь» и «верстак». Новые рецепты открываются из книг и от жителей.
- **База:** заколачивание окон, костёр, буржуйка, верстак, сборщик дождевой воды, сигнализация из банок.
- **Навыки** растут от использования (9 навыков), **черты** выбираются при создании персонажа (13 черт).
- **Враги:** «Кашляющие», «Бродяги», «Громилы» (идут на шум и свет, ломают двери), степные собаки, бандиты «Волки степи» с оружием.
- **Скрытность:** шум шагов, удар со спины втрое сильнее, ночью без фонаря тебя почти не видно.
- **День и ночь, погода:** пыльные бури, ливни, раз в 3–4 дня — «Пыльный фронт».
- **Колхоз «Заря»:** 4 жителя с расписанием, диалоги в стиле Fallout 2 (проверки навыков), бартер.
- **Языки:** казахские и узбекские слова в речи с переводом при первой встрече и словарик. Записки на узбекском и казахском нужно переводить: у переводчика или навыком «Языки».
- **Радио «Океан»:** 3 частоты, сводки, предупреждения о фронте, странные передачи.
- **Сохранения:** режимы «Обычный» и «Суровый» (одна жизнь). Сохранения лежат в `%APPDATA%\Granica99\saves`.

## Структура проекта

```
main.py            — точка входа
game/              — код игры (модули описаны в CODE_JOURNAL.md)
data/              — все тексты и данные в JSON: предметы, рецепты, диалоги, задания, радио
build.bat          — сборка .exe через PyInstaller
CREDITS.md         — источники графики, звука и библиотек
CODE_JOURNAL.md    — журнал «что делает этот код» для защиты проекта
```
